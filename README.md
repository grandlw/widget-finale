# Grandl Rank Widget
Kişisel Android Solo/Duo rank widget'ı. Profil: grandl#wave (TR).

- OP.GG Solo/Duo rank, LP, W/L ve WR
- 6 saatte bir WorkManager yenilemesi (Android zamanlamayı pil durumuna göre geciktirebilir)
- Manuel yenileme
- Gün içi LP farkı (aynı division içindeki snapshot farkı)
- Rank'a göre otomatik rozet

## GitHub Actions ile APK
Actions > Build Android APK > Run workflow. Yeşil tamamlanınca Artifacts > GrandlRankWidget-APK.
